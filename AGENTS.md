# desktop.engineer — AGENTS.md

## Commands

| Command | Notes |
|---------|-------|
| `pnpm dev` | Vite dev server |
| `pnpm build` | Runs `scripts/generate-pwa-icons.mjs` then `vite build` |
| `pnpm preview` | Preview production build from `dist/` |

Always `pnpm`. No `npm` / `yarn`.

## Stack

- **Vue 3** (`<script setup>`) + **Vue Router 4** (lazy routes, `createWebHistory`)
- **Tailwind CSS v3** (not v4 — uses `tailwind.config.js` + `postcss.config.js`)
- **DaisyUI v4** (not v5 — `require("daisyui")` in tailwind.config.js; theme toggle via `theme-controller` checkbox)
- **Vite 8** + **vite-plugin-pwa** (service worker, offline support)
- **No TypeScript, no test framework, no linter, no formatter**
- Font Awesome 6 Free via CDN (`all.min.css`) for icons — no emojis in UI

## i18n

Custom composable in `src/i18n/index.js`:
```js
import { useI18n } from '@/i18n'
const { locale, t, setLocale } = useI18n()
```
- Locale files: `src/i18n/locales/{fr,en}.js`
- Persisted in `localStorage` key `de_locale`. Default: `fr`.
- All user-facing strings must use `t('namespace.key', { param: val })`.

## Key conventions

- **`@/`** import alias → `src/`
- **Backticks inside JS template literals in `.vue` files** must be escaped with `\`` (Vue compiler requirement)
- **`data-theme="dark"`** on `<html>` in `index.html`. Theme-controller checkbox toggles to `light`.
- **Navbar dropdowns** use JS-managed hover state (not DaisyUI `dropdown-hover`) — see `hoveredCat` / `openDropdown` / `closeDropdown` in `App.vue`
- **Cookie consent** gates all `localStorage` writes (key `de_cookie`). Store: `src/stores/appStore.js`.
- **SEO** per route via `src/seo.js` → `applySeo()` called in App.vue's route watcher
- **PWA icons** auto-generated by `scripts/generate-pwa-icons.mjs` on build

## Architecture

- **Entry**: `index.html` → `src/main.js` → `App.vue` + router
- **17 tools**, each in `src/views/*.vue`, all lazy-loaded except Home
- **Router**: `src/router/index.js` — `createWebHistory`, `scrollBehavior({ top: 0 })`
- **Store**: `src/stores/appStore.js` — `reactive()` singleton, `useAppStore()` composable, localStorage-backed
- **No server, no API, no analytics** — 100% client-side, zero back-end dependencies

## Tool-specific gotchas

- **SshKeyGenerator**: RSA/ECDSA via Web Crypto API (works in browser). Ed25519 → instructional `ssh-keygen` command only (not supported by browsers).
- **SslCertGenerator**: Uses `@peculiar/x509` (requires `reflect-metadata` polyfill imported in main.js). Encrypted PKCS#8 (PBES2/PBKDF2-HMAC-SHA256 + AES-256-CBC) implemented in `src/utils/ssl.js` with Web Crypto — no extra dependency.
- **PublicKeyAnalyzer**: Decodes binary OpenSSH blob client-side. Includes custom MD5 for fingerprints.
- **HashChecker**: Files >50MB processed via Web Worker (`src/workers/hashWorker.js`) with chunked FileReader (1MB chunks). Small files use SubtleCrypto directly.
- **FormatConverter/LinterFormatter**: Depend on `js-yaml` for JSON/YAML/CSV conversion.
- **KeyFormatConverter**: Instructional only (outputs shell commands), no actual binary conversion.
- **EnvKeyGenerator/PasswordGenerator**: All randomness via `crypto.getRandomValues()`.
- **CronGenerator**: Uses `cronstrue` dependency.
- **SubnetCalculator**: Uses `ipaddr.js` dependency.
